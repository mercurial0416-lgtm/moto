# MOTO HUB Alpha6 DI(518) — 정비·주유 간편 입력 (소스 전용)

## 적용한 변경

- 정비·주유를 시작할 때 오늘 날짜와 현재 선택 바이크 계기판을 자동 제시하고 수정 입력칸은 접어 둠. 원하면 언제든 펼쳐 날짜·거리를 확인하고 수정할 수 있음.
- 주유: 지난 유효한 **해당 바이크** 주유 기록의 리터당 가격을 *참고값*으로 표시. 금액 → 리터 / 리터 → 금액 계산은 **버튼을 눌렀을 때만** 동작하고, 결과는 추정값으로 안내함. 최근 주유값 복사와 가득 주유 버튼 추가.
- 정비: 엔진오일·오일필터·체인·브레이크·타이어·냉각수 빠른 선택. **해당 바이크 + 동일 정비 항목**의 이전 비용/메모만 명시적 동작으로 재사용. 다음 거리 기록은 과거 절대값 복사가 아니라 이전 간격만 새 계기판으로 옮기며, 다음 날짜는 초기화함. 직접 작업 0원 버튼 추가.
- 기존과 동일한 AtomicFile 원본/백업·초안 저장 경로를 사용. 새/수정 기록 저장 시 차량과 연결된 계기판이 과거 값으로 낮아지지 않음.
- 날짜·거리·종류·금액·주유량이 같은 기록이 있으면 신규 저장 전에 확인 대화상자를 띄워 **중복 저장만 사용자에게 확인**. 기존 기록을 병합·삭제하지 않음.
- 정비·주유 기록 목록 상단에도 별도의 빠른 추가 버튼 노출.
- 보험·부품·기타 비용을 입력할 때 주유 전용 리터당 가격 안내 숨김.

## 검증 범위와 제한

- Java 구문 파싱 + 새 순수 Java 정책 테스트 + 선택한 기존 회귀 스크립트만 검증. Android SDK 기반 컴파일/Lint/APK 빌드/실기기 입력은 **요청대로 실행하지 않음**.
- 이전 고정 서명 인증서와 버전코드 518 유지. 키스토어/비밀번호/토큰은 소스 파일에 포함하지 않음.
- 기존 517 앱에 소스만 설치할 수 없음. 이후 빌드 시 반드시 보존된 **동일 고정 서명키**로 서명하고 기존 데이터 백업 후 실제 덮어쓰기 설치 검증 필요.
- 영수증 인식/OCR·유가 실시간 조회·현장 OBD2·Supabase 실제 계정 조작은 구현/검증하지 않음.
- 유지비 화면에서 최근 6개월 기록을 바이크별로 한 번만 집계하며, **주유 / 기타 비용 / 정비 비용**을 따로 표시. 기존 월별 지출 변화와 예정 정비 알림은 유지.
- 같은 항목 정비 재사용 시 기존 간격을 계산한 뒤 해당 선택 항목을 펼쳐 사용자가 직접 확인하도록 변경.
