# MOTO HUB v604 – 연결 상태·자동기록 문제 해결

v603의 쉬운 연결 도우미에서 추가로 실제 오류 경로 10개를 개선했습니다.

1. Bluetooth 연결 권한 없음과 Bluetooth 전원 꺼짐의 진단 순서를 분리합니다.
2. 카르도 자동시작에 Android 10+ 백그라운드 위치 권한이 필요하다는 것을 사전에 표시하고, 미허용이면 알림으로 수동 시작하도록 안내합니다.
3. Android 설정 화면에서 앱으로 돌아오면 살아 있는 연결 도우미의 상태/다음 버튼을 갱신합니다.
4. 카르도 오디오 프로필 검사를 MAC당 하나로 합치고 응답을 최대 4초만 기다리며, 늦은 응답은 이중 처리하지 않습니다.
5. 실제 ECU 속도 PID 010D 수신 여부를 다른 센서의 성공과 분리해 동글별로 저장·표시합니다. PID 지원 선언 비트맵은 실측 응답과 다르게 표시합니다.
6. **자동기록 없는 연결 검사**는 권한·카르도 오디오 프로필을 조회하며, ECU 테스트는 사용자가 직접 선택한 읽기 전용 검사로만 진행합니다. 라이딩 GPS 파일을 시작하지 않습니다.
7. 마지막으로 성공한 ECU 센서 검사 시각을 바이크+동글별로 보존합니다.
8. 카르도 연결, OBD 속도, GPS 시작, 저장·차단을 카테고리별 로컬 이벤트 20개까지 보관합니다. GPS 좌표와 MAC을 저장하지 않습니다.
9. 첫 자동주행 검증 실패 시 좌표 부족/0.1km 미만/검증 실패 이유를 표시합니다.
10. 권한·상태·진단 이력을 한 번에 클립보드에 복사하고, 주소/좌표를 포함하지 않거나 마스킹합니다.

**중요:** 이 앱은 독립 패키지 `com.motohub.next.obdpreview604`인 시험용 설치판입니다. 기존 v599/603을 삭제하지 마세요. 데이터가 자동 이전되지 않습니다. Android 정책과 듀크390 ECU, 실제 동글 및 카르도의 환경별 동작은 실차 검증이 필요합니다. ECU 설정/고장코드/계기판 ODO를 자동 변경하지 않습니다.
