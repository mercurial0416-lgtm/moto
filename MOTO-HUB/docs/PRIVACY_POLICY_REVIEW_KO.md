# MOTO HUB 개인정보처리방침 — 배포 전 검토 초안

> 이 문서는 **Google Play 공개 전 검토용 초안**입니다. 운영자 연락처, 데이터 삭제 요청 경로, 실제 Supabase 보관 기간과 권한 정책을 확인하고 공개 URL에 게시하기 전까지 확정 방침으로 사용할 수 없습니다.

## 처리 대상과 목적
MOTO HUB는 바이크 주유·정비·부품·매물, GPS 라이딩 기록, 선택된 바이크의 누적 주행거리 등 사용자가 입력한 데이터를 기기에 저장합니다. GPS 사용은 사용자가 주행기록 기능을 시작하고 위치 권한을 허용했을 때 또는 개발자 실험 OBD 자동 감지를 직접 켠 상태에서 수행됩니다. 기록에 쓰이는 경도·위도·시간 등은 기기에 저장되며, 사용자가 직접 내보내거나 선택적으로 공유하는 기능을 제외하고 내비 앱으로 자동 전달되지 않습니다.

선택적 친구·그룹 기능을 켜면 계정 식별자·프로필 정보·친구 요청 및 그룹 정보가 인증된 Supabase 서비스에 전송될 수 있습니다. 라이딩 중 사용자가 그룹 위치 공유를 명시적으로 시작하면 위치 좌표, 방향, 시간, 이동 상태가 해당 그룹의 위치 공유 서비스를 통해 전송될 수 있으며 공유를 중지할 수 있습니다. **실제 서버 보관 기간과 로그 정책은 운영자가 확인해야 합니다.**

바이크 모델 사진을 온라인으로 검색하면 모델명·제조사·연식 등 검색어와 일반적인 서버 접속 정보가 Wikimedia Commons에 전달될 수 있습니다. GPX 경로 지도에서 온라인 배경지도를 직접 켜면 지도 영역의 타일 요청이 외부 지도 서버에 전송됩니다. 웹 페이지나 매물 링크를 열면 해당 외부 사이트의 개인정보처리방침이 적용됩니다.

## 선택한 내비 앱
카카오내비, 네이버지도, 티맵은 사용자의 직접 선택에 따라 해당 앱만 실행합니다. MOTO HUB가 사용자의 현재 위치·저장된 GPS 경로·OBD 센서값을 내비 앱에 자동 전송하지 않습니다. 내비 앱을 실행한 이후 앱에서 처리하는 정보는 해당 서비스의 정책에 따릅니다.

## 접근 권한
- 정확한 위치: 사용자의 라이딩 기록 및 사용자가 선택한 그룹 위치 공유.
- 알림 및 포그라운드 서비스: 주행기록 진행 상태·정비 알림과 종료 조작.
- Bluetooth 연결: 실험적인 OBD2 장치를 사용자가 직접 연결할 때.
- 카메라/기기 파일: 사용자가 사진·영수증을 선택하거나 기록을 가져오기/내보내기할 때.
- 네트워크: 선택한 온라인 서비스, 친구·그룹, 사진 검색, 온라인 지도 타일 등.

Google Play 설치판은 직접 APK 설치 권한을 요청하지 않습니다.

## 보관 및 삭제
바이크 데이터, 로컬 GPS 기록, 사진과 개인 설정은 일반적으로 기기에 저장됩니다. 앱의 개별 삭제·전체 백업 및 복구 기능에 따라 사용자가 데이터를 관리할 수 있습니다. 앱 삭제 시 로컬 데이터가 지워질 수 있습니다. 암호화 백업을 외부 저장공간에 별도 보관한 경우 해당 파일은 사용자 관리 대상입니다.

Supabase 서비스로 전송된 계정/그룹/위치 데이터의 구체적 보관·삭제 처리와 운영자 문의 경로는 **Play 출시 전에 서버 정책 및 계정 삭제 흐름을 감사한 뒤 기재**해야 합니다.
