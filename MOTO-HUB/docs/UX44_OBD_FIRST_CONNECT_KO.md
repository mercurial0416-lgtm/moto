# UX44 — Vgate BT3.0 첫 OBD 연결 흐름

## 범위
- 수동 사용자 동의를 전제로 기존의 Bluetooth Classic SPP(ELM327) 읽기 전용 경로 유지
- 바이크 시트 아래 유로5 6핀 변환 케이블 연결, 시동 ON, 갤럭시 Bluetooth 페어링, ECU 표준 센서 테스트의 흐름을 화면에 표시
- 페어링된 기기는 **이름으로 정렬만** 하고 모든 기기를 표시. 기타 헤드셋 등을 Vgate로 잘못 선택하기 쉬운 문제 완화
- Bluetooth 연결만으로 차량 ECU 호환이라고 오판하지 않도록 속도 PID 지원 여부, 유효 샘플 수신 여부를 구분하여 표시
- ECU 일시 무응답은 센서 단위로 처리. 전체 센서 3주기 연속 무응답 시 중단 및 케이블·시동 점검 문구 제공
- 라이딩 탭에 개발자 모드 사용자의 OBD 연결/검사 진입점 추가
- Android 12+ Bluetooth 권한 요청 뒤 ODO 실험 조회가 일반 센서 검사로 바뀌던 오류 수정

## 안전성
- ECU 설정 및 DTC 변경 없음. GPS 기록 자동 시작은 여전히 별도 동의/실험 모드에서만 가능
- 속도 PID 010D의 실차 데이터 수신을 확인하기 전 자동 기록 가능하다고 주장하지 않음
- 한국 내 2024 KTM 390 DUKE 실차 테스트는 미완료
- 서명·기존 데이터 구조·앱 ID·메인 업데이트 manifest 변경 없음
