# MOTO HUB 4.0 Alpha6-F — 빠른 입력 UX 패치

기반: Alpha6-E 원본 ZIP. `versionCode 411`, 버전명 `4.0.0-alpha6-f`. 서버 프로젝트, 데이터 모델, 위치 공유 API, RLS는 변경하지 않음.

## 패치 내역

- 바이크 등록: 보유/관심 모델을 포함한 모델명 버튼, 연식 선택, 구매가 선택.
- 정비: 정비 항목 프리셋, 날짜 선택 달력 및 오늘/어제, 현재 바이크 주행거리 불러오기, 금액 버튼, 차기 정비 거리 편의 옵션.
- 비용/주유: 비용 종류 바로 선택, 주유 금액·리터 선택, 날짜 자동 입력, 현재 주행거리, 직전 비용 항목 재사용(직전 날짜/거리 미복사).
- 매물: 금액/연식/지역/모델 버튼. 다른 앱에서 공유한 http(s) 매물 링크를 MOTO HUB로 보내면 매물 저장 폼에 URL 자동 채움. 공유 텍스트가 간단한 제목이면 모델명도 제안.
- 라이딩 그룹: 방 이름 템플릿.
- 친구: 32자리 코드 클립보드 붙여넣기, 코드 공유(안드로이드 공유하기), 프로필 바이크 이름을 로컬 차고에서 제안.
- 이미 연결된 Supabase 서버 주소/키는 일반 친구 화면에서 숨김. 변경은 설정 > 친구 서버 고급 설정에서 가능. 초기 기본값은 기존 공개 설정을 유지.
- 날짜 입력은 EditText 직접 타이핑 대신 Android DatePickerDialog 사용, 일반 필드는 사용자가 직접 수정할 수도 있음.
- Android 폼을 열 때 키보드를 자동으로 펼치지 않고, 숫자 필드를 편집할 때 기존 값 전체를 선택.
- GitHub Actions는 **APK 빌드에 성공하면 즉시 APK를 먼저 보관**하고, 이후 lint/단위테스트 진행. 버전별 소스 ZIP도 체크포인트로 보존.

## 확인된 검증

- `bash tests/run-offline-tests.sh`: 19건 통과
- `bash tests/run-server-settings-tests.sh`: 16건 통과
- `bash tests/run-quick-entry-tests.sh`: 12건 통과
- JDK 17 Java 구문 파싱: 앱 Java 소스 21개 오류 없이 파싱
- 프로젝트 기본 공개 서버 URL/key 및 마이그레이션 보존
- 이 환경에서 Android SDK/API 36을 사용할 수 없어 APK 컴파일, UI 클릭 테스트, 실기기 GPS 테스트 **미수행**. 따라서 아직 Alpha6-F 설치 APK가 없음.

## 사용법 예시

1. 주유 기록 > 날짜·현재 주행거리 자동 채워짐 > 금액/리터 버튼 선택 > 저장.
2. 엔진오일 정비 > '엔진오일' 선택 > 정비금액 선택 > 필요하면 예정 거리 선택 > 저장.
3. 매물 앱/브라우저 > 공유하기 > MOTO HUB Next > 링크 자동 입력 후 모델/금액 확인 > 저장.
4. 친구 코드 받은 채팅에서 코드 복사 > MOTO HUB 친구 코드 입력 > 클립보드에서 코드 붙여넣기 > 친구 요청.

## 안전/정확성

- 정비주기 제안 버튼은 단순 편의상 거리값. 제조사 정비주기를 뜻하지 않으므로 사용자 확인 필수.
- 비용·주유량·매물 가격을 인터넷에서 자동 조회하지 않음. 예시 버튼 또는 직접 입력.
- 이전 기록 재사용 시 현재 날짜/주행거리는 바꾸지 않음.
- 클립보드는 버튼을 직접 누른 경우에만 읽음.
- 사용자 위치·연락처 접근은 이번 패치에서 추가하지 않음.

## APK 빌드

GitHub Actions `MOTO HUB Android checkpoint APK + source` 혹은 JDK17/Android SDK36 환경에서 `./gradlew :app:assembleDebug`. 디버그 APK는 `app/build/outputs/apk/debug/app-debug.apk`. 기존 앱 덮어쓰기 가능 여부는 APK 서명 일치 여부에 달려 있음. **앱 삭제 전 로컬 JSON 백업 권장.**
