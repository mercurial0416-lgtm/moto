# UX92 실제 패치 및 배포 게이트

- UX91: CI 성공 후 release/moto-hub-apk 브랜치에 squash 병합함 (PR #113).
- UX92: 홈 대표 사진을 UI 스레드에서 디코딩하지 않고 8MiB 제한 캐시와 작업자 스레드 사용. 바이크 전환 시 잘못된 사진 적용 방지.
- GPS: 완료 기록 알림에 수신 공백 횟수와 실제 관측 구간 표시. ODO 자동 반영 없음.
- OBD: 오래된 ECU 속도 숨김 명확화, 자동 감지 재연결은 GPS 기록과 자동 감지가 꺼진 경우에만 직접 요청. 실차 검증은 여전히 필요.
- 주유: 최근 기록 재사용 도구를 접히는 영역으로 이동하고 이상 입력 경고에 바이크·날짜·리터·금액·계기판 값을 출력. 기존 기록, 임시 초안, 중복 차단 규칙은 보존.
- 설정/백업: 현재 DB와 마지막 검증된 전체 ZIP의 SHA-256 일치 상태 표시; 기기 외부 보관 여부는 자동 확인 불가. 업데이트의 현재 버전과 설치 인증서 호환성 표시.
- 배포: 기존 동일 package com.motohub.next 및 인증서 SHA-256 212c5b39d0082ab4bed78f8da2b719819cd80a20bc116c84f8bdfabca507021b 필수. 서명/암호는 GitHub 소스에 포함하지 않음.
- **테스트 성공과 설치 가능한 고정서명 APK 배포는 별개**. 실제 배포 manifest가 새 번호를 가리키고 공개 APK SHA, size, signature, package, versionCode까지 검증되기 전에는 배포 완료라고 표현하지 않음.
- 오프라인 전체 ZIP은 개인정보(GPS 포함) 처리에 주의. 원래 앱 삭제하지 말 것.
