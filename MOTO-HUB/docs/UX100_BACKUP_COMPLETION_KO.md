# MOTO HUB UX100 · v563 백업/복원 신뢰성 패치

- UX99 v562 소스 PR #121은 Android 빌드와 테스트 통과 후 릴리스 소스에 병합했습니다.
- `LocalSafetyBackup.checkpoint`는 실제 영속 저장·재열기·바이트 대조까지 성공했는지 반환합니다. 복원 완료 UI에서는 실패를 숨기지 않습니다. 유효한 체크포인트가 생성된 뒤 과거 파일 정리에 실패하더라도 그 체크포인트는 지우지 않습니다.
- 새 SAF ZIP 내보내기는 검증 전에 실패하면 내보내기 URI의 불완전 파일 삭제를 시도하고, 삭제 실패를 명확히 표시합니다. 이미 ZIP 재검증을 통과한 경우에는 증명 저장에 실패해도 정상 ZIP을 삭제하지 않습니다.
- GPS 전용 분할 내보내기는 사진·영수증·모델 사진 폴더 목록을 검사하지 않습니다. MEDIA 전용은 GPS 폴더 목록을 검사하지 않습니다. FULL은 둘 다 검사합니다.
- 전체 ZIP 사전 점검의 원본 바이트 및 수량 집계에 GPS 복구함과 직접 선택한 모델 사진 및 출처 메타데이터를 포함합니다. 안전하지 않은 파일과 상태 마커 용량도 계산합니다. 이 사전 점검은 GPX 변환 결과나 ZIP 성공을 보장하지 않습니다.
- 자동 복원 지점 목록이 비어 있을 때는 파일 없음과 손상/권한 오류를 구별해 알립니다. 손상 파일을 자동 복원 대상으로 제공하지 않습니다.
- ZIP 성공 표시 항목 수는 검증된 ZIP 항목 목록의 실제 크기를 사용합니다. `BackupBundle.export()`의 반환 수량도 GPX, README, 모든 상태 부속 파일을 포함하도록 맞췄습니다.

## 테스트
- `UX100BackupCompletionTest`: GPS 복구함, 모델 사진, ZIP 항목 수, GPS 전용 분할 격리, 과도한 상태 마커 사전 점검
- `tests/run-ux100-backup-completion-tests.sh`: 위 6개 소스 경로에 대한 회귀 검사
- `tests/run-ux99-backup-enumeration-tests.sh`: 의도한 분할별 열거로 검사식 수정
- 전체 Java/Android/Robolectric CI 회귀 게이트 통과 전 병합하지 않습니다.

## 배포 제약
- package `com.motohub.next`, 사용자 데이터 형식 및 기존 APK 서명키를 변경하지 않았습니다.
- v563은 소스 릴리스 후보입니다. 원본 서명 인증서가 확인된 APK가 실제로 게시되기 전까지 사용자 단말의 업데이트가 완료된 것으로 보고하지 않습니다.
