# MOTO HUB 제품 원칙 (항상 이 순서)

1. **UI:** 첫인상, 타이포그래피, 대비, 정보 계층, 화면 간 일관성, 작고 넓은 화면 대응. 실제 실행을 검증하기 전에는 스크린샷/동작 보장으로 표현하지 않는다.
2. **편의성:** 입력보다 선택, 기본값은 검증 가능한 현재 데이터, 클릭/스크롤/키보드 호출 최소화, 잘못된 자동 추측 금지, 미저장 초안 유지.
3. **필요성:** 실제 바이크 사용자에게 필요하며 유지보수 가능한 기능만 추가. 사용성에 이득 없는 기능/장식 및 광고성 화면을 추가하지 않는다.

변경 시 데이터 영속성과 GPS 공유 기본 OFF, 위치 권한/공유 종료, RLS 보안, 업데이트 서명 호환성 보존을 우선 확인한다.

개발 단위: 한 화면/흐름마다 점검→실제 수정→로컬 검사→산출물 ZIP. APK는 Android SDK와 컴파일 성공이 확인된 경우만 배포.


## Alpha6-H 시그니처 홈
홈은 다크 MY GARAGE/주황색 포인트 UI를 기준으로 유지합니다. 등록 데이터가 없는 상태에서 데모 수치를 실제값인 것처럼 보여주지 않습니다. 대표 바이크 사진은 직접 바꿀 수 있으며 GPS 기록은 명시적 시작/종료를 요구합니다.
