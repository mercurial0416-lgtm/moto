# MOTO HUB 4.0.0 Alpha6-H — MY GARAGE UI 체크포인트

**UI → 편의성 → 필요성** 우선순위를 적용한 홈 화면 집중 패치입니다.

## 변경 사항
- `GarageHomeUi.java` 신설: 상단 MY GARAGE 타이틀, 알림·설정, 바이크 사진 히어로, 연식·상태, 주행거리/다음 정비/이달 라이딩 카드, 주행 시작/종료, 주유·정비·기록 바로가기, 저장 매물 2건, 친구 진입, 최근 기록 2건.
- 주황색 (#FF6B1B)과 차콜 기반 다크 홈 디자인. 기본 신규 설치 테마를 다크로 지정하고, 기존 명시적 테마 설정은 유지. 홈 시그니처 화면은 다크로 렌더링.
- 실제 저장된 바이크 이름/연식/주행거리/정비 기록/로컬 GPS 트랙/관심 매물/친구 공유 상태에서 데이터를 읽습니다. **UI 시안의 예시 수치를 앱에 하드코딩하지 않았습니다.**
- 생성된 바이크 기본 아트는 **예시 이미지**로 표기. '사진 변경'을 누르면 Android 이미지 파일 선택기로 사용자의 사진을 지정하고 기기 내부에 JPEG로 저장합니다. 이미지를 업로드하지 않습니다.
- 라이딩 시작은 기존 `RideUi.requestStart()`의 위치 수집 안내·권한 확인을 재사용. 기록 중일 때 버튼은 종료 확인 대화상자로 변경됩니다.
- 긴 입력 없이 클릭 동작 연결: 주유->기존 비용 폼, 정비->기존 정비 폼, 기록->기존 라이딩, 저장 매물->기존 상세, 친구->기존 서버 친구 화면.
- 앱 버전 `4.0.0-alpha6-h` (versionCode 413), GitHub Actions 산출물명도 같은 버전으로 갱신.
- 파일 안 `docs/previews/alpha6-h-design-preview.html`은 **디자인 시안**, 실제 Android 실행 캡처가 아닙니다. 표시된 샘플 숫자는 예시입니다.

## 검증

- `tests/run-server-settings-tests.sh`: 16개 통과.
- `tests/run-quick-entry-tests.sh`: 12개 통과.

- Android Gradle/APK 컴파일 및 실기기 화면·조작 테스트: **미실행**. SDK를 이 환경에서 이용할 수 없으며 외부 다운로드 DNS도 차단되어 있습니다. APK 산출물 없음.
- Android SDK가 준비된 빌드 환경에서 `./gradlew :app:assembleDebug` 후 앱 설치 및 화면 테스트 필요.

## 주의
- 기본 바이크 이미지는 생성된 **예시** 사진입니다. 정확한 내 바이크 사진이 아닙니다. 홈의 '사진 변경'으로 변경할 수 있습니다.
- 새로 저장한 바이크 사진은 앱 내부 파일로 보관되므로 기존 JSON 백업에 포함되지 않습니다. 앱 삭제 전 별도로 원본 사진을 보관해야 합니다.
- 이달 주행 횟수는 **기기에 저장된 모든 GPS 트랙 파일 수**입니다. 바이크별로 구분하는 기능은 아직 없습니다.
- 라이딩 녹화와 그룹 실시간 GPS 공유는 서로 다른 기능이며, 홈의 주행 시작 버튼만 누르는 것은 친구에게 좌표를 보내지 않습니다.
- 서버 및 실기기 연결을 이번 UI 패치에서 재검증하지 않았으며, 기존 Supabase 스키마/서버 프로젝트는 수정하지 않았습니다.
- 이전 버전과 서명 불일치가 발생할 수 있으니 기존 설치본을 삭제하지 말고 데이터 백업 후 테스트하세요.
