# UX95 v558 개발·서명 배포 원칙

- 기기 내 전체 ZIP 백업 검증 당시 GPS 원본 파일명을 함께 저장하여 이후 새 GPS가 있는 경우 DB 해시가 같아도 새 백업 필요를 표시. 단, 사진·GPS 내용 해시는 별도 검증이며 외부 ZIP 파일 존재는 확인하지 않음.
- GPS 기록 실행 중 매 60초 이하 빈도로 저장공간 확인. 32MiB 아래에서 경고하고 8MiB 미만에서는 기록을 미완료 상태로 종료해 기존 .track 원본을 복구 화면에 보존. 공간 조회 실패 시 자동 중단하지 않으며 저장 오류는 기존 예외 처리로 보존.
- 온라인 모델 사진의 로컬 캐시 JPEG는 백그라운드 한정 큐에서 디코딩, 미리보기 교체/모델 변경 시 뒤늦은 결과 폐기, 손상된 캐시는 온라인 검색으로 대체.
- 원본 고정서명 OTA 배포 워크플로는 해당 릴리스 소스 SHA의 Android CI `apk` 검사 성공을 확인하고 UX93/UX95 회귀검사를 통과한 경우만 서명 발행. 테스트 성공은 휴대폰 실물 검증을 대체하지 않음.
- GitHub 브랜치 보호 강제는 저장소 관리자 권한이 필요. 연결된 GitHub App의 권한으로 관리자 ruleset을 설정할 수 없음. 권장 필수 검사: `apk`, `android-debug-check`; 병합 전 최신 커밋 통과 필수.
- `release-code.txt=558`, package `com.motohub.next`, 인증서 SHA-256 `212c5b39d0082ab4bed78f8da2b719819cd80a20bc116c84f8bdfabca507021b` 유지. 임의 새 서명으로 기존 앱 업데이트 금지.
- 기존 고정 서명키는 비공개 Library 및 사용자 소유 상태로만 사용. 키/암호를 저장소나 PR, GitHub artifact로 올리지 않음.
