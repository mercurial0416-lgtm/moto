# MOTO HUB 534 — 빠른 출발과 내비 실패 복구

기존 533의 중단 라이딩 복구 알림·내비 복귀 수정과 모든 데이터 보존 기능을 유지합니다.

- 홈의 GPS 시작 버튼 중복 노출을 제거합니다. 라이딩이 꺼진 상태에서는 동의 후 GPS+기본 내비를 실행하는 단일 출발 버튼을 사용합니다.
- 이미 라이딩 중이거나 OBD 자동 감지가 켜져 있다면 GPS 종료 또는 자동 감지 관리 버튼을 유지합니다.
- 선택한 외부 내비가 열리지 않으면 현재 설치된 다른 내비 앱을 선택해 곧바로 실행할 수 있습니다. 사용자 선택 시 기본 내비 설정과 위젯이 함께 갱신됩니다.
- 세 종류의 내비 앱 설치 확인 결과를 선택 목록에 표시합니다.
- CI 테스트용 JSON 라이브러리 다운로드에 보조 Maven Central 호스트를 추가해 빌드 서버 일시 장애를 줄입니다.
- 개인 위치 정보, GPS/GPX 경로, OBD 기록은 외부 내비에 전달하지 않습니다.
- 기존 패키지 com.motohub.next, 고정 서명 인증서 및 데이터 보존 정책을 유지합니다.

릴리스는 통합 회귀 테스트, Android 빌드·린트·단위 테스트, 고정키 오프라인 서명과 SHA-256 검증이 완료된 후에만 게시합니다.
