# OBD 지원 센서 전체 탐색 (실험)

- 경로: 모토허브 > OBD 연결 3단계 > **지원하는 전체 센서 탐색 · 실제 수신값 확인**
- 개발자 모드 OBD2 화면에서도 **ECU 전체 지원 센서 탐색 · 선별** 제공
- 안전: 정차 상태에서만 사용. 자동 라이딩 감지를 끈 뒤 사용. 표준 SAE Mode 01(현재 데이터) 읽기 외 ECU 명령 없음.
- 동작: PID 0100부터 지원 목록의 확장 비트가 있는 페이지(0120, 0140, ..., 01E0)만 따라가며, 해당 ECU가 지원한다고 표시한 Mode 01 PID를 각 1회씩 요청. 매 요청 타임아웃과 중단을 지원하며 반복해서 전수 스캔하지 않음.
- 결과: 실제 정상 응답을 받은 PID만 표시. RPM·속도·온도·전압·연료량·스로틀·부하·점화시기·일부 거리·엔진 경고 정보 등 확인된 공식 수식만 단위 변환. 정의하지 않은 PID는 **원시 HEX/단위 미확인**으로 표시.
- ODO: 표준 \`01A6\`을 ECU가 **지원한다고 알리고 실제 응답도 있으면** 총주행거리 후보만 표시. 계기판 값과 일치하는지 별도로 확인해야 하며 자동 저장/차고 주행거리 변경을 하지 않음. \`0121\`과 \`0131\`은 *경고등 점등/고장코드 삭제 이후 거리*이므로 총주행거리로 사용하면 안 됨.
- 선택: 체크박스에서 관심 PID를 골라 저장하고, **선택한 센서만 다시 읽기**에서 그 PID만 새로 수신. 저장 데이터는 PID 번호뿐이며 원시 ECU 응답·VIN·블루투스 MAC·위치정보는 저장하지 않음.
- 예외: 표준 진단 지원 목록/실제 값 미응답은 ECU 미지원 또는 네트워크 오류일 수 있음. 제조사 비공개 PID/UDS 탐색은 수행하지 않음. 바이크 ECU 구성에 따라 계기판 ODO 자체가 표준 PID로 노출되지 않을 수 있음.
- 배포: 기존 앱 패키지·서명·DB·자동 라이딩/정비·GPS 기능 유지. 원래 앱을 삭제하지 말 것. 새 APK로 설치할 때 서명과 versionCode를 별도 검증해야 함.

단위 검증은 실차 계기판과 비교해서 판단. 주행 중 스마트폰 조작 금지.
