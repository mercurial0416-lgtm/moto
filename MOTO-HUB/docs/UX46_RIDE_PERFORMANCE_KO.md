# UX46 · 자동 라이딩 / 오프라인 분석 / 정비 연동 개선

## 새 기능
- 정차 중 사용자 요청 시에만 이번 OBD 자동 라이딩의 정차 종료 기준을 10분으로 연장. 이는 주유나 휴식을 자동으로 판별한다는 뜻이 아니다.
- 속도 0~2km/h의 정상/최근 OBD 샘플을 받은 라이딩에서만 연장 가능. 블루투스가 끊겼을 때 GPS 기록은 이전과 동일하게 보존.
- 라이딩이 끝나면 연장 시간을 기존 3/5/10분 기본 설정으로 복귀.
- 버튼 명칭을 "OBD 자동 감지만 중지"로 구체화, 정차 중에만 휴식 연장 버튼 표시.
- 갤럭시 큰 글씨 및 작은 화면에서 GPS 기록 실시간 카드가 세로로 전환.
- "최근 완료 라이딩 · 주행거리·정비 확인" 버튼. 저장된 최신 GPS를 **사용자 확인을 통해서만** 계기판에 반영하는 기존 기능으로 이동. 기존 중복반영 방지 로직과 정비 알림 갱신 재사용.
- 15분 단위 구간별 GPS 이동거리·관측시간·이동시간 추정. GPS 미수신/긴 갭은 정차로 추정하지 않음. 사용자가 요청할 때만 백그라운드에서 파일 분석.
- 홈의 중단 GPS 복구 추천을 백그라운드 파일 검사로 변경, 오래된 화면의 검사 결과는 폐기.
- ECU 선택적 RPM·수온·전압 폴링을 정차/주행 속도에 맞춰 회전. 실제 데이터 지원은 실차 확인 필요.

## 기존 구현 재사용
- JSON과 GPS 경로는 기기 로컬에 유지, 네트워크 연결 불필요.
- 수동 GPS 기록, 라이딩별 중복 적용 차단, 직접 승인 후 계기판 ODO 반영, 반영 뒤 정비 계산/알림은 기존 제공.
- 앱 재시작 시 자동 페어링/위치 기록 재개하지 않음.

## 릴리스
Android debug assemble + lint + 단위 테스트, UX38~UX46 정책 검사를 통과하더라도 기존 설치 앱과 일치하는 서명 키를 통한 release 빌드 전에는 배포 금지.
