# MOTO HUB 4.0 Alpha6-G — UI 우선 패치

기반: `MOTO-HUB-4.0.0-alpha6-f-source.zip`, 앱 패키지 `com.motohub.next`, schema3/로컬 `motohub-v3.json` 유지, `versionCode=412`.

## 사용자 우선순위

**UI 1순위 → 편의성 2순위 → 필요성 3순위.** 다음 업데이트에서도 우선순위 유지. 자세한 사항은 `docs/PRODUCT_PRIORITIES_KO.md`.

## 패치

- 홈: 프리미엄 다크/라이트 팔레트, 크게 표시되는 바이크명·주행거리, 월 유지비/기록 연비, 바로 기록(주유·정비·라이딩), 점검과 최근 기록으로 이어지는 흐름.
- 매물: 실시간 로컬 이름 검색(별도 검색 버튼 제거), 가격 우선 카드, 상태 배지, 주행거리·연식·지역, 최대 3대 선택 비교 및 필터/정렬.
- 폼: 추천 선택값을 키보드 입력창 위로, 선택값 시각 강조, 달력 선택, 저장 버튼 고정. 비용 타입이 보험/부품/기타면 주유량/가득 주유 입력을 숨기고 저장 시 리터를 0으로 처리.
- 전체: 탭/툴바/행/모달 스타일 정리, 초안 이어쓰기 배너를 홈/기록 화면에서만 표시.
- 친구: URL 기술정보를 메인 화면에서 제거, 프로필·그룹 액션 재배치, 위치 공유 상태 명확하게 표시.
- 위치 공유: 공유 중 어느 탭에서나 즉시 종료 가능한 상단 버튼. 그룹 지도에서 위치 공유 중지가 필요할 때만 버튼 표시.

## 검증과 미검증

- `tests/run-offline-tests.sh`: 19건 통과.
- `tests/run-server-settings-tests.sh`: 16건 통과.
- `tests/run-quick-entry-tests.sh`: 12건 통과.
- JDK17 문법 파서: Java 21개 구문 오류 없음.
- **Android SDK 없음: assembleDebug/Android Lint/실기기 렌더링·클릭·GPS 테스트 미수행. APK 배포 불가.** Java 구문 검사는 Android API 타입·메서드 호출의 컴파일 성공을 보장하지 않음.

## 보존 범위

- 기존 정비/주유/매물/GPX/라이딩/소셜 백엔드·서버 설정, Supabase RLS 정책, 실시간 GPS 5초 주기 방식, 사용자 위치 공유 기본 OFF 원칙 유지.
- CI GitHub Actions 설정은 `alpha6-g` 산출물 이름으로 수정. GitHub 저장소에 커밋·push되지 않았으며 Actions 실행 검증 전.
- 기존 APK 덮어쓰기 설치는 서명이 일치해야 하며, 앱 삭제 전 데이터 백업 필수. JSON 백업에 GPS 트랙은 포함되지 않으므로 GPX로 별도 내보내기.
