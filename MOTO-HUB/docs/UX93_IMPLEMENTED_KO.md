# UX93 실사용 신뢰성 패치

v557 소스에 다음 네 가지를 추가했다.

1. **주유 이상입력 경고**: 문자열에 남는 문자 그대로의 백슬래시-n을 제거하고 실제 줄바꿈으로 표시. 저장·중복 검사 로직은 유지.
2. **GPS 저장공간**: 내부 저장공간 48MiB 미만이거나 용량을 확인할 수 없으면 새 GPS 파일 생성 전에 안전하게 거부. 일반 출발과 OBD 자동 시작 모두 서비스 측에서 최종 재검사. 기존 GPS 원본은 삭제하지 않음.
3. **손상된 차고 개인사진**: 백그라운드 사진 디코딩이 실패할 때 원본을 그대로 두고 동일 모델/연식 참고 이미지 검색으로 안전하게 대체. 인터넷 또는 모델 정보가 없으면 안내 표시. 원본이 정상인 경우 기존 사용자 사진 우선 정책 유지.
4. **라이딩 목록**: 화면 진입 시 메모 데이터의 JSON 스냅샷을 고정하고 백그라운드 기록 탐색에서는 스냅샷만 사용. 원본 DB와 기록을 변경하지 않음.

기존 com.motohub.next 패키지 및 고정 서명 인증서 지문은 불변. UX93 테스트를 CI에서 수행해 Android 빌드+회귀 통과 후 병합. 공식 고정 서명 APK가 v557로 출시되는 것은 별도이며 기존 설치본 삭제는 금지.
