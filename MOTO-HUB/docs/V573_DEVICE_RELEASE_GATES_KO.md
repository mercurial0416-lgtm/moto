# MOTO HUB v573 · Android 16 실기기 배포 게이트

이 문서는 **테스트 완료 보고서가 아니라 수행해야 할 검증 목록**입니다. v572 실사용 앱을 삭제하거나 디버그 APK로 덮어쓰지 않습니다.
릴리스는 `release/moto-hub-apk` 소스의 CI 결과와 원본 고정 서명, 실제 단말 확인이 모두 충족된 후 별도 진행합니다.

## 1. 데이터 보호 (필수)
- [ ] v572 설치 상태에서 외부 저장소로 **전체 ZIP 백업**을 저장하고 파일 크기/열기/검증 확인
- [ ] 주유·정비·라이딩·GPS·사진·바이크 ID 개수를 기록
- [ ] 같은 서명의 **검증된** 테스트 릴리스로 설치 후 자료 수량과 SHA-256 증거 비교 (가능하면 두 번째 시험 기기)
- [ ] ZIP/JSON 복원, 앱 강제 종료 중 복원, 저장공간 부족 대응 검증. 실사용 단말에서 파괴적인 복원 실험 금지
- [ ] 사용자 데이터 삭제·스키마 변경·서명키 공개 없음

## 2. GPS (필수)
- [ ] Android 16 화면 잠금/화면 꺼짐, 외부 내비(카카오·네이버·티맵) 전환 중 30~60분 경로 연속 기록
- [ ] 정차 후 10분, 터널 등 신호 소실/재수신 시 **허위 직선 연결 없음**
- [ ] 권한 해제/알림 금지/저장공간 부족 시 기록 보존 및 명확한 오류 안내
- [ ] 라이딩 중 앱 강제종료 뒤 복구 대상과 정상 완결 파일 구분; 원본 백업 비교
- [ ] 녹화 중 OS가 서비스를 종료할 때의 실제 Android 동작 기록 (자동 복구 성공을 추정하지 말 것)

## 3. 2024 KTM Duke 390 + ELM327 (실차 필요)
- [ ] 사용자가 직접 동글·6핀 변환 케이블 연결, 주변 기기 권한 허용
- [ ] 시동 OFF/ON, 연결 해제·재연결·동글 전원 차단 후 앱 반응 확인
- [ ] 표준 010C RPM, 010D 속도, 0105 수온, 0142 전압, 012F 연료 비율 지원 여부 **개별 확인**
- [ ] 01A6 ODO는 지원 비트맵과 동일 센서 값 검증 전 **계기판 누적거리 자동 갱신 금지**
- [ ] GPS 단독 주행은 OBD 실패와 무관하게 계속되고, ECU 쓰기·오류 삭제는 수행하지 않음

## 4. v573 신규 UI/기능 (필수)
- [ ] 저장 라이딩 상세→지도→리플레이 펼치기→재생/일시정지/슬라이더가 동작
- [ ] 지도 네트워크 꺼짐이 기본이고 사용자가 별도 동의하기 전 온라인 타일 요청 없음
- [ ] 앱을 백그라운드로 보내면 리플레이 일시정지, 화면 닫아도 원본 GPS/사이드카 불변
- [ ] 최근 6개월 통계에서 다른 바이크 비용이 섞이지 않음; GPS 미기록 구간을 실제 km당 비용으로 오인하지 않게 표시
- [ ] 설정의 라이딩·OBD·백업 진단은 좌표·주소·장치 고유 ID·토큰을 노출하지 않음
- [ ] 360dp/412dp 폰트 1.0·1.3, 라이트/다크 테마, 스크롤/누르기/대화상자 배치 점검

## 5. 설치/배포 (필수)
- [ ] `assembleDebug`, `testDebugUnitTest`, `lintDebug` 및 통합 Java 회귀 통과
- [ ] 신규 APK의 applicationId가 `com.motohub.next`이고 versionCode가 573인지 확인
- [ ] `apksigner verify --print-certs` 결과 SHA-256이 `212c5b39d0082ab4bed78f8da2b719819cd80a20bc116c84f8bdfabca507021b`와 동일
- [ ] 원래 설치본에 **삭제 없이** 덮어쓰기 설치 성공 및 재실행 후 업데이트 데이터 감사 통과
- [ ] 원본 서명 APK 실증 전 `main/updates/manifest.json` 변경 및 공개 OTA 발행 금지

검증 실패 항목은 증상, OS 버전, 발생 절차, 로그 요약(개인정보 삭제)을 별도로 남겨 재현·수정합니다.
