# UX43 · 안정성 및 사용성 전체 개선

## 변경 내역
1. **복구 지점 보존**: 설치 전 만들어진 스냅샷과 마지막으로 검증된 설치 전 스냅샷은 일상적인 12개 백업 로테이션에서 제외. `UpdateRecoveryPolicy`는 이름 형식을 검사하여 임의 파일 보호 금지.
2. **다운로드 취소**: 진행 중 화면에서 명시적으로 중단할 수 있음. HTTP 수신 루프에서 중단 요청을 확인하고 `<sha256>.part.apk` 파일을 지우지 않아 다음 시도에서 기존 UX42의 엄격한 HTTP Range 검사 후 이어받기 가능. 설치 전 검증/백업 작업은 중단 버튼 대상이 아님.
3. **주유/정비 UX**: 기본 주유 설명 중복 제거, 정비 알림 세부 옵션을 별도 펼치기로 이동, 거리·날짜 둘 다 미설정인 정비주기 저장 차단. 기본 예고 설정 유지, 정비 주기는 제조사 매뉴얼을 사용자에게 확인하도록 안내.
4. **가독성**: 폰트 1.35배 또는 화면 폭 360dp 미만이면 홈 빠른 동작 버튼·정비 목록의 제목과 버튼·홈 링크를 세로로 배치. 스피너·검색창은 고정 높이 대신 최소 높이로 동작.
5. **GPS 안정성**: 위치 저장 뒤 표시되는 알림과 GPS/OBD 워치독 알림 오류를 `notifySafely`로 격리. 알림 서비스 사용 불가 시 원격 위치공유는 보수적으로 불허. 파일 영속화 경로와 출발 foreground 요건은 그대로 유지.
6. **오류 문구**: 네트워크 DNS·시간초과·TLS·권한 오류는 구체적 한국어 조치로 표시하고 내부 서버명·Java 예외를 사용자에게 노출하지 않음.
7. **테스트**: 순수 Java `UpdateRecoveryPolicyTest` 9건, `UpdateErrorTextTest` 8건 로컬 javac로 컴파일/실행 통과. UX42 `UpdateResumePolicyTest` 18건 재실행 통과. GitHub 코드에서 이어받기/서명/백업 등 추가 정적 검사.

## 배포 주의
- 기존 서명 지문과 저장 데이터 구조를 변경하지 않음. 비공개 키 존재 및 사용, 실제 Android APK 인증서 일치는 실기기/Android CI 검증 전까지 미확인.
- Android SDK와 Gradle 앱 빌드 환경이 현재 작업 컨테이너에 없어 `assembleRelease`, 실기기 네트워크·설치·업데이트 검증은 미완료. APK 배포나 원격 manifest 수정을 하지 않음.
- 앱 삭제 금지. 백업은 사용자가 실제 전체 ZIP/암호화 백업으로 내보내야 사진/GPS를 포함할 수 있음.
