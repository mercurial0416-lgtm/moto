# 4.0.0-alpha1 UI 체크포인트
기존 3.2 저장 구조·CRUD 재사용. 홈 하단 빠른 기록, 리스트형 매물, 정비/주유 탭, 아이콘 하단 내비게이션, 친구 지도 전용 진입, 전체 화면 입력 폼과 고정 저장 버튼으로 구조 변경.
친구 지도는 연결 대기 안내이며 실제 지도/친구 기능 구현 완료가 아님. GPS 수집 없음.
에뮬레이터 검증 진행 중이며 아직 UI 시각 검증·Android16 실행 통과를 주장하지 않음.
3.2 이번 세션 체크포인트와 동일한 debug 서명. 첨부 3.1 서명과는 다름. 실제 업데이트 데이터 보존은 별도 테스트 필요.
