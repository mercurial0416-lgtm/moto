# 바이크별 OBD 연결 설정

경로: **설정 > 바이크 관리 > 내 바이크 관리 > OBD 연결 설정**.

- 바이크를 선택한 후 해당 바이크에 사용할 Bluetooth Classic OBD2 어댑터를 **페어링된 기기** 목록에서 지정.
- 저장되는 데이터는 바이크 UUID와 연관된 **동글 Bluetooth 주소/이름 및 선택한 표준 Mode 01 PID 번호**. 로컬 SharedPreferences에만 보관하며 기존 차량 DB·정비·주행 기록을 수정하지 않음.
- 바이크 A와 B는 서로 다른 어댑터 및 센서 선택값을 보관. 같은 어댑터를 두 바이크에 등록해도 됨.
- OBD 탐색 화면에서 **현재 바이크에 등록된 동글을 목록 최상단 표시**. 선택한 표준 PID는 현재 바이크에만 저장되며, 다른 바이크로 전환해도 선택값이 섞이지 않음.
- 동글 등록만으로 ECU 연결/자동 라이딩이 시작되지는 않음. 사용자가 명시적으로 센서 조회/자동 감지를 시작해야 함.
- Android Bluetooth 페어링은 시스템 설정에서 별도로 진행하며 이 앱이 강제로 페어링을 해제하지 않음.
- 바이크 영구 삭제가 성공한 경우에만 해당 바이크의 OBD 로컬 설정을 정리. 판매 보관/정비·주유 이력은 유지.
- ECU 총주행거리(01A6)가 응답하더라도 실계기판 대조 전 차량 주행거리 DB는 변경하지 않음.
- 기존 모토허브 서명·데이터 보호: 독립 \`com.motohub.next.obdpreview\` 앱으로 배포된 APK는 원래 앱과 공존하며, **원본의 DB/라이딩 기록을 자동 승계하지 않는다**.
- 실차 테스트: 정차/키 ON에서 동글 연결 검사 후 선택 센서/실제 RPM·속도·수온 등을 계기판과 비교. 동글 전원이 키 OFF에서 차단되는지 별도 확인. 주행 중 앱 조작 금지.
