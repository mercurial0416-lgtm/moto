# MOTO HUB 4.0.0-alpha6-m · 연식별 사진 선택 경합 수정

## 이번 수정 (UI 정확성 / 편의성)

**문제:** 차고/등록 화면에서 브랜드·모델·연식을 빠르게 바꾸면, 먼저 시작한 온라인 이미지 조회가 늦게 완료되면서 최신 선택을 이전 차종 사진으로 덮어쓸 수 있었습니다. 예를 들어 Honda Super Cub 110 (2024) 검색 후 Yamaha YZF-R3 (2023)을 선택했는데, Honda 응답이 늦게 도착하면 잘못된 이미지가 표시될 수 있었습니다.

**수정:** `PhotoRequestGuard`의 약한 참조(WeakHashMap) 기반 요청 세대 토큰을 이미지 뷰마다 발급합니다. 오래된 응답은 최신 토큰과 일치하지 않으면 UI에 적용하지 않습니다. 같은 연식을 다시 검색한 경우도 이전 응답은 폐기됩니다. 새 검색 시 이전 이미지의 출처 링크도 즉시 제거합니다. 기존 이미지 캐시·모델 검색·개인 사진 우선 정책은 유지했습니다.

## 아직 확인되지 않은 항목

- Android APK 빌드 **실패(환경 문제)**: Gradle 8.11.1 배포 파일이 캐시에 없고 `services.gradle.org`에 DNS 접속이 되지 않음. Android SDK도 로컬에서 발견되지 않음.
- 갤럭시 실기기 실행, 온라인 사진 조회, Supabase 두 기기 위치 공유, 푸시·내비·매물 실시간 수집은 이 실행에서 검증/구현하지 않음.
- 이 수정은 사진이 **정확한 연식임을 인증하는 기능은 아님**. 검색 후보·참고 사진 표시 정책은 유지.

SDK/Gradle이 설치된 빌드 환경에서 `./gradlew :app:assembleDebug`를 실행하고 설치 테스트. 온라인 이미지가 없을 때의 플레이스홀더/접근성 UI 개선 검토.
