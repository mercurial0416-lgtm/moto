# MOTO HUB 4.0 Alpha6-J — 카탈로그·연식 이미지 패치

## 이번 버전에 실제 반영된 코드
- 기존 Alpha6-I 네이티브 소스 재사용: 기존 정비·주유·매물·GPS/GPX·친구·Supabase·백업 기능 코드 유지.
- 바이크 및 매물 등록 폼: `브랜드 → 모델 → 연식` 검색형 선택 UI. 직접 입력 유지. 고른 브랜드/모델은 백업 JSON에 `catalogBrand`, `catalogModel` 키로 함께 보관하며 과거 데이터와 호환.
- 오프라인 카탈로그: 49개 브랜드/522개 모델 (`app/src/main/assets/motorcycle_catalog.json`). 한국어 별칭 예: 슈퍼커브, 헌터커브, 듀크390, 닌자400.
- 카탈로그 바깥의 제조사도 직접 등록 가능. 온라인 버튼을 누르면 미국 NHTSA vPIC 제조사 목록 및 제조사+연식 motorcycle 모델 목록을 조회해 보완. 미국 시장 신고자료라 전 세계/국내 모든 모델을 보증하지 않음.
- 연식 이미지: Wikimedia Commons 파일 검색에서 제목에 **제조사+모델+연식 문자열**이 모두 포함되는 이미지만 후보로 선택. CC 등 라이선스 및 출처 상세 링크를 확인하고 캐시. 사진 제목이 정확한 제품 연식을 증명하지 않으므로 반드시 **연식 검색 후보**, 미검증 문구 유지.
- 후보 사진을 찾지 못하면 사용자의 사진을 우선, 슈퍼커브는 참고 일러스트, 그 외에는 중립 이미지로 표시. 엉뚱한 차종/연식을 확정 사진처럼 표시하지 않음.
- 앱 버전 `4.0.0-alpha6-j`, versionCode 415.

## 검증 완료
- 오프라인 카탈로그 무결성 49브랜드·522모델, 중복 ID 없음, 주요 모델/별칭 존재 및 UI 연결 검사 통과.
- Java 25개 파일 Java 17 **구문 파싱 통과**(Android API 타입 검사와 다름).
- 기존 로컬 테스트 19+12+12+16 = 59개 통과.
- 분리된 웹 미리보기에서 Yamaha → YZF-R3 → 2023년식 선택, 홈 반영 및 브라우저 콘솔 오류 없음 검증.

## 아직 검증하지 못한 것
- Android SDK가 없어 실제 APK 컴파일/설치·화면·네트워크 동작은 미검증.
- NHTSA 및 Wikimedia Commons에 대한 실시간 API 요청은 네트워크 테스트 환경 제한으로 미검증. 응답/라이선스/연식 후보 존재 여부는 차종별로 다를 수 있음.
- 522개 모델에 모든 생산연도/배기량/공식 사진이 입력됐다는 의미가 아님. 모델 검색 초기 후보 목록이며 선택 연식의 실제 생산 여부는 제조사에서 확인 필요.
- 테스트용 HTML은 브랜드/모델/연식 선택 기능 시연용이며 네이티브 앱의 주유·GPS·친구 등의 실행을 대신하지 않음.

## 빌드
개인 Android/Gradle 빌드 환경에서 `./gradlew :app:assembleDebug`. GitHub Actions `.github/workflows/android-debug.yml`이 APK를 먼저 보관하도록 설정됨. 서명/기존 앱 데이터 호환을 반드시 실기기에서 확인 후 배포할 것.
