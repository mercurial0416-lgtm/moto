# UX101 · v564 통합 안정화 점검

이 PR은 새로운 기능을 무한히 늘리는 대신, 사용자 데이터를 내보내고 검증하고 복원하는 경로를 하나의 회귀 검증 단위로 묶습니다.

## 반영 범위

1. **대용량 분할 ZIP:** 필수 원본 폴더가 존재하는데 목록 읽기에 실패한 경우 빈 목록으로 간주하지 않고 실패합니다. GPS와 미디어를 빠짐없이 분할 계획합니다. 유효하지 않은 수동 선택 모델 사진의 출처 메타데이터는 조용히 건너뛰지 않습니다.
2. **GPS 복구함:** 알 수 없는 폴더/부속 파일, 복구함 원본 누락, 읽기 불가능한 폴더는 사용자에게 오류를 알려 원본 분실 위험을 숨기지 않습니다.
3. **원본↔분할 ZIP 바이트 검증:** 모든 분할 ZIP 항목을 재확인하고 해당 원본 파일 크기 및 SHA-256과 비교합니다. 동영상이 아닌 사진/메타데이터/GPS 부속파일까지 대조합니다. 변경된 원본이 있으면 파일을 정상 백업으로 보고하지 않고 부분 생성 파일 삭제를 시도합니다.
4. **일반 JSON 복원:** 실제 복원은 유지하되, 후속 안전 체크포인트 저장 실패를 완료 메시지에 알립니다. 복원 완료를 실패로 뒤집거나 기존 데이터를 삭제하지 않습니다.
5. **수동 JSON/GPX 내보내기:** 메인 스레드 파일 쓰기를 별도 스레드로 옮기고, 크기 제한과 저장 후 SHA-256 재읽기를 적용합니다. 검증 실패 시 불완전한 SAF 문서의 삭제를 시도하고 남으면 명시적으로 안내합니다.
6. **릴리스 안정성:** 기존 `com.motohub.next`, JSON 스키마, GPS 원본, 기존 서명키 지문은 변경하지 않습니다. 서명되지 않은 v564 소스 후보와 실제 v556 공개 APK를 구분합니다.

## 검증

`tests/run-ux101-consolidation-tests.sh`은 순수 Java에서 분할 ZIP 생성·재검증·같은 길이 파일 변조 탐지·GPS 복구함 문제·읽기 실패 폴더를 테스트합니다. 통합 소스 검사는 Android 수동 내보내기 및 체크포인트 실패 메시지 연결도 확인합니다. 기존 전체 회귀 + Android lint/unit test 성공 전 병합 금지.

## 남는 현실적 제약

현실 장비(안드로이드 기종/SAF 공급자/장시간 GPS 이동/OBD 연결)는 CI 만으로 완전히 증명할 수 없습니다. 기존 개인 서명키 없이 업데이트 APK를 새 서명으로 다시 게시하면 사용 중인 앱과 호환되지 않으므로, 원본 서명키가 없는 상태에서는 기존 앱 삭제나 신규 키로 APK 교체를 안내하지 않습니다.
