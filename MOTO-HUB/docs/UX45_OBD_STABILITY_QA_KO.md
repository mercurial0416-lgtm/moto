# MOTO HUB UX45 · 듀크390 OBD 연결 안정화 / 실차 점검

이번 변경은 Vgate iCar Pro BT3.0 / EURO5 6핀 케이블을 구매한 사용자를 위한 개발이다. **실제 KTM ECU와의 통신 성공을 주장하지 않는다.**

## UX45 범위
- OBD 속도 샘플 급변값(2.5초 이내 전 값과 60km/h 초과 차이)을 자동 GPS 출발 트리거에서 제외. 잘못된 값이 출발 상태를 누적하지 않도록 카운트 초기화
- 자동 출발의 3회 샘플 간격을 5.5초 내로 제한. 이미 기록 중일 때의 중단/정차/동기화 정책은 유지
- 새 연결마다 ECU 지원 PID를 **다시 검사**하고, 마지막 확인 목록은 별도 로컬 SharedPreferences에 참고용으로만 보존. 기존 개인정보/라이딩 파일과 분리
- 좌표, 원시 ECU 값, Bluetooth MAC, 사용자 계정을 저장하지 않는 허용 코드 기반 로컬 진단 이벤트 최대 12개
- 개발자 OBD 화면의 이전 결과 확인 및 삭제, 시동 OFF/장기 주차 시 동글 대기전류 주의
- 라이딩 탭에 속도 신선도·연결 재시도 상태 표시
- 스크롤 가능한 큰 글씨 대응 디지털 대시보드, 읽기 전용 RPM 막대(범위 0–15000은 시각화 범위이며 제조사 레드라인 아님), 냉각수 110°C 이상 또는 RPM 수신 중 이상 전압에 대한 **참고용** 안내. 값이 오래되면 경고에 사용하지 않음
- GPS/주유/정비/계기판 ODO 자동 변경 및 ECU 쓰기 기능 추가 없음
- CI javac 테스트 + Android 디버그 assemble/lint/test. 정식 릴리스는 기존 인증서 일치 및 설치 데이터 보존 확인 이후에만 허용

## 사용 전 체크
1. 바이크 시동 OFF로 동글에 전류가 계속 흐르는지 실측하기 전까지 장기 주차에는 동글 분리
2. 정차 상태에서 Bluetooth 3.0 페어링 및 ECU 센서 검사
3. 속도 PID 010D 미지원 시 자동 출발 기록 사용 불가 (수동 GPS 가능)
4. 일관된 속도·RPM·수온 샘플 수신 확인, 정차 중 센서 무응답 여부 확인
5. 안전한 환경의 실차 주행으로 자동 기록 시작·정차 종료·앱 잠금·전원 상태/배터리 사용 검사
6. 원래 앱 삭제하거나 서명이 다른 디버그 APK 덮어쓰기 금지
