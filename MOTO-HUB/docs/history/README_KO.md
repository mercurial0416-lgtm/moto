# MOTO HUB Next 3.2.0-dev 소스 / 3.1.0 APK

> **추가 인수인계 (3.2.0-dev):** 이 프로젝트의 소스는 3.2.0-dev까지 변경됐지만, 현재 함께 제공된 APK는 기존 **3.1.0-preview** 빌드입니다. 새 기능이 APK에 아직 반영되지 않았습니다. `docs/CURRENT_HANDOFF_KO.md`를 먼저 읽으세요. 이 변경본의 Android SDK 빌드/실기기 검증은 아직 하지 않았습니다.


이전 임시 작업공간이 자동 정리되어 소스·APK·SDK·테스트 원시 파일이 사라졌습니다. 이 프로젝트는 같은 대화에 남아 있는 코드와 설계를 바탕으로 재구성한 복구본입니다. 이전 바이너리/소스의 바이트 단위 동일 복사본이 아닙니다. 복구 체크포인트를 먼저 전달한 뒤 초안 보존과 연비 기능을 추가했습니다. 이전 테스트 25+13개 결과를 이 복구본의 테스트 결과로 주장하지 않습니다.

## 현재 구현
실제 Android 네이티브 화면 (WebView 없음), 5탭, 다중 바이크 CRUD/대표 선택, 주유/비용/정비 CRUD, 월 집계, 정비 예정과 보험 만료 앱 내 표시, 매물 검색/상태/정렬/가격 이력/3개 비교/구매 체크리스트, 수동 코스와 외부 지도, 장구 관리, 시스템/밝은/어두운 테마. AtomicFile 저장과 SAF JSON 백업/복원, v1 데이터 이관, 복원 직전 사본, 손상 백업 검증.

## 실행
JDK 17 / Android SDK 36 / Build Tools 36.0.0 / Gradle 8.11.1 / AGP 8.10.1.
Android Studio에서 루트 폴더를 열거나 Gradle 설치 후:

    ./gradlew :app:assembleDebug

APK: app/build/outputs/apk/debug/app-debug.apk. SDK 경로는 본인 PC의 local.properties에 설정합니다. local.properties 및 키 파일은 포함하지 않습니다.

## 설치와 데이터
패키지 com.motohub.next, 원래 com.motohub.app와 별도 설치. 기존 앱을 지우지 말고 JSON 내보내기 → 새 앱 더보기 → JSON 가져오기. 기존 앱의 파일 내보내기가 동작하지 않을 경우 기존 앱을 삭제하면 안 됩니다. 새 앱은 다른 앱의 private storage를 읽을 수 없습니다.

개발용 서명 APK는 운영용 릴리스가 아닙니다. 이전 작업의 개발 키도 사라졌으므로 이전 Next APK와 서명이 다를 수 있습니다. 설치 충돌 시 먼저 백업을 보관하고 본인 릴리스 키 체계를 정해야 합니다. 서명키는 코드/ZIP/채팅에 넣지 않습니다.

## 미완성
친구 로그인·초대·차단·그룹·실시간 GPS·Foreground Service·서버 접근제어는 미구현. GPS를 수집하거나 전송하지 않음. 화면에 백엔드 연결 대기 표시.
주기 템플릿/OS 예약 알림, 제원 비교, 기변 비용, GPX 입출력, HTTPS 업데이트도 후속 항목. 원본의 watchlist/shops/specs/routes.points 등은 JSON에서 보존하지만 관련 화면은 일부 미이관.

## 이번 개선
- 입력 중인 폼의 가장 최근 초안 하나를 앱 내부에 저장. 홈 상단에서 이어쓰기/초안 삭제. 저장 완료하면 초안을 제거합니다. 초안은 JSON 백업 대상이 아닙니다.
- 주유에 '가득 주유' 체크 추가. 차고에서 가득→가득 주행거리/중간 주유량을 기반으로 연비 표시. 기록 누락 시 부정확하며 예전 기록은 자동 추정하지 않습니다.
- 입력 오류를 한국어로 안내하고 저장 완료 기록은 AtomicFile로 보호합니다.

## 검증
현재 버전: Gradle APK 빌드/서명 검사/Lint 통과, JVM 테스트 35개 통과. 실제 Android 실행·화면 폭/확대·초안 복구는 새 버전에 대해 미검증입니다. 자세한 결과는 TEST_RESULTS_KO.md.

먼저 저장한 3.0.1 복구 ZIP/APK는 별도 체크포인트로 유지됩니다. 3.1.0 APK는 이번 세션의 3.0.1과 같은 개발키로 서명하여 덮어쓰기 가능하도록 빌드했습니다. 더 오래된 Next APK와는 서명이 다를 수 있으므로 백업 확인 후 설치하세요.
