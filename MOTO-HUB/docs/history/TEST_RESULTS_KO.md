# 3.1.0-preview 검증 결과

## 이번 세션에서 직접 재검증
- 3.0.1 복구 소스 Gradle APK 빌드·서명 검사 성공. 추가 개발 전 복구 소스 ZIP 및 APK를 먼저 저장·전달함.
- 3.1.0 Gradle assembleDebug 및 lintDebug 성공. 원시 기록: evidence/build-3.1.txt 및 lint-3.1.txt.
- JVM 데이터 모델 25개 + 연비 계산 10개 = 35개 통과. evidence/model-3.1.txt. 테스트는 재현 가능한 Java 파일로 포함.
- APK v2/v3 서명 검증 결과: evidence/signature-3.1.txt. 디버그 서명이며 운영용 릴리스가 아님.

## 새 기능의 테스트 범위
연비: 첫/단일 가득 주유만으로 계산하지 않음, 중간 부분 주유 합산, 첫 가득 주유량 제외, 여러 구간 가중 계산, 바이크별 격리, 누락 주유량으로 인한 구간 무효 처리, 역행/동일 주행거리 거부, 기존 기록에 fullTank 추정 금지, 백업 후 fullTank 유지 등 10개 시나리오 통과.

초안: 편집 필드 변경·종류 선택·가득 주유 선택·onPause 시 임시저장, 닫기/재실행 후 이어쓰기, 저장 완료 시 초안 제거, 삭제된 차량/원본에 잘못 재연결하지 않는 검증 로직을 구현. 실제 Android 기기에서의 강제종료/회전/키보드/저장공간 부족은 아직 재검증하지 못함. 초안은 가장 최근 폼 하나만 보관하며 JSON 내보내기에는 저장 완료 기록만 포함됨.

## 미검증을 통과로 표기하지 않음
- 이번에 재구성한 3.0.1/3.1.0의 실제 휴대폰/에뮬레이터 실행은 미검증.
- 이전 세션의 Android 9 instrumentation 13개 통과는 이전 바이너리 결과임. 원시 파일이 소실되어 새 빌드 결과에 합산하지 않음.
- 이전 스크린샷은 System UI ANR 대화상자로 가려졌고, 320/360/393/412dp 폭 변경도 캡처 크기로 검증되지 않았음. UI 확대/폭 매트릭스 통과를 주장하지 않음.
- Galaxy S25/Android16, SAF 파일앱 왕복, 프로세스 종료 도중 AtomicFile 복구, 초안의 실기기 복구는 후속 실기기 검증 필요.
- 친구/GPS/Foreground Service/서버 RLS는 미구현. 두 계정 위치 공유 테스트도 하지 않음.

## 중요한 파일 상태
원래 작업공간의 소스·APK·테스트 결과가 자동 정리되어 원본 바이너리를 복구하지 못했음. 대화에 남은 코드 기반으로 재구성했으며 바이트 동일성을 보증하지 않음. 현재 ZIP은 전체 Android 프로젝트이며 소스에서 다시 빌드 가능. 비밀 서명키는 제외.
