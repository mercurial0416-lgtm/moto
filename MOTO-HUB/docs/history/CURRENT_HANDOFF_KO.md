# MOTO HUB 3.2.0-dev — 다음 세션 인수인계

**필독: 첨부 APK는 기존 빌드 3.1.0이며 3.2.0-dev 기능이 들어 있지 않습니다.**

## 이번 작업에서 직접 확인한 사항
- 받은 `MOTO-HUB-3.1-source-and-apk.zip`에 Gradle 네이티브 Android 소스와 서명된 `MOTO-HUB-3.1.0-preview.apk`가 들어 있었음.
- APK SHA-256: `be1de9d3e88b0f16d5c295f9c42e17943189cb9182a66e6708e4b2bc38e3b61b`. ZIP 내부 기존 증빙 해시와 일치.
- 기존 문서에는 Gradle 빌드·Lint·JVM 모델 35개 통과가 기록돼 있음. 이 세션에서 35개를 재실행한 것은 아님.
- 이 세션의 환경은 Android SDK와 Gradle 다운로드에 필요한 외부 네트워크가 없어 APK를 재빌드할 수 없었음.

## 이번에 3.2.0-dev 소스에 추가한 기능
1. **기변 비용 계산기**: 더보기 → 바이크 교체 비용 계산하기. 구매가, 등록/명의이전 예상비, 탁송, 초기 정비, 장비비, 처분대금을 원 단위로 입력해 총 취득비·추가 현금·잔여 현금 추정. 외부 시세/세금 실시간 조회 아님.
2. **정비 임박 정렬**: 홈에서 만료/주행거리 도달 → 30일/500km 이내 → 예정 순으로 최근 정비 항목을 우선 표시. 보험 만료도 같은 상태 구분 사용. 앱 화면을 열 때 계산되며 OS 푸시 알림은 아님.
3. **출발 전 점검 체크**: 라이딩 탭의 확인 상태를 기기 내부에 날짜 및 차량별 보존. 다음 날짜로 바뀌면 새 상태로 시작. JSON 백업 대상 아님.
4. **빠른 차량 전환**: 다수 바이크 등록 시 홈에서 바로 차고 차량 선택으로 이동.
5. **재현 가능한 빌드 설정**: `.github/workflows/android-debug.yml` 추가. GitHub Actions 실행은 이 세션에서 하지 않았음.

## 검증 및 한계
- JVM 17 기반 순수 Java 신규 테스트 **19개 통과**. 증빙 `evidence/offline-features-this-session.txt`.
- 신규 UI의 Android 컴파일/에뮬레이터/갤럭시 S25 실기기 테스트는 **미실행**. 앱 전체 동작을 검증했다고 주장하지 않음.
- 친구 로그인, 백엔드, 그룹, 실시간/백그라운드 GPS, GPX, OS 알림, OTA 업데이트는 여전히 **미구현**. 미구현 상태를 UI에서 숨기지 않음.
- Android 9/16·폭 320/360/393/412dp·텍스트 130%·파일 백업 round-trip은 추가 검증 필요.

## 다음 작업 우선순위
1. Android Studio 또는 CI에 프로젝트를 열어 `./gradlew :app:assembleDebug :app:lintDebug` 실행 → 설치 가능한 **새 APK** 즉시 전달.
2. 갤럭시 S25 등 실기기에서 등록, 수정, 저장, JSON 백업과 가져오기, 정비 임박 상태, 기변 계산기를 테스트.
3. 화면 캡처/사용자 피드백으로 UI 구조 개선 (과도한 카드·장식 대신 접근성·터치 영역·상태 우선 표시).
4. 친구·실시간 GPS는 별도 서버, 명시적 공유 동의, 방 구성원별 RLS, 좌표 만료, foreground service를 단계적으로 개발.

## 설치 주의
- 패키지: `com.motohub.next`. 원래 `com.motohub.app`과 다른 앱.
- 받은 3.1 APK는 **디버그 키**로 서명됨. 새로운 환경의 3.2 디버그 키와 서명이 다르면 덮어쓰기 안 될 수 있음. 사용 중인 앱 데이터를 먼저 JSON으로 백업한 뒤 설치 전략 결정. 비밀키를 소스/채팅에 공유하지 말 것.
- 앱 설치만으로 기존 `com.motohub.app` 데이터를 자동 이관할 수 없음. 앱 내 JSON 백업과 복원 필요.
