# UX99 · 백업 누락 방지 및 사전 검증 보강 (소스 릴리스 후보 562)

- **폴더 목록 실패 시 중단:** 기존 ZIP 내보내기는 앱 내부 사진/영수증/GPS/수동 선택 모델 사진/격리된 GPS 기록 목록 읽기에 실패할 때 이를 빈 폴더처럼 간주할 수 있었다. 존재하는 폴더의 열람 실패를 명시적 IOException으로 차단한다. 없는 선택 폴더는 계속 빈 상태로 처리한다.
- **GPS 상태 파일 8종 사전 검사:** 완료, 가져오기, 복구, 병합 취소, 병합 대상, 바이크 ID, 카테고리, 즐겨찾기 마커의 타입·크기·심볼릭 링크를 확인한다. 모든 상태 파일의 원본 바이트 수를 계산에 포함한다.
- **백업 크기 경계 보정:** ZIP 안내문 README-KO.txt의 원본 바이트도 250MB 한도 계산에 포함한다.
- **회귀 테스트:** UX99BackupEnumerationTest.java (실파일, 잘못된 마커, 심볼릭 링크, 빈 차고 ZIP) + run-ux99-backup-enumeration-tests.sh. CI의 Android/Robolectric 테스트도 통과해야 한다.
- **비파괴 원칙:** `com.motohub.next` 유지. 기존 JSON·GPS·사진·서명키·사용자 앱 데이터 변경하지 않음. release-code 562는 소스 후보이며, 동일 원본 인증서의 서명 APK 및 검증된 manifest가 없으면 앱 내 OTA로 게시하지 않는다. 기존 설치 앱을 삭제하지 않는다.
