# MOTO HUB 4.0 Alpha6-K · 실제 기능 확장 체크포인트

우선순위: **1. UI → 2. 편의성 → 3. 필요성**. 기존 Alpha6-J 네이티브 소스를 사용했으며 소스 코드를 교체했지 WebView 모형을 배포하지 않았다.

## 이번 체크포인트의 구현 코드

### UI
- 라이딩 카드에 준비/진행 상태, 큰 시작/종료 버튼, 진행 중 거리·경과시간·속도를 추가했다.
- 기록 목록에서 하나를 누르면 거리/경과시간/평균·최고속/제외된 GPS 오차점과 원본 파일 확인이 가능하다.
- 지도 화면(`RideMapActivity`)에 저장된 트랙을 주황색 경로로 표시하며, 출발/도착 표시를 추가했다. OSM 지도 타일은 네트워크를 사용한다.
- 차고 `MY BIKE INSIGHTS`: **선택 바이크 기준** 이번 달 정비·주유 비용 및 가득→가득 주유 연비를 표시한다.
- 바이크 이미지는 정확한 연식 검색 후보 우선, 없으면 **같은 모델의 연식 미확인 후보**(명확히 표기), 없으면 슈퍼커브 참고/일반 placeholder, 직접 업로드 사진이 최우선이다.

### 편의성
- 로그인 토큰을 AndroidKeyStore AES-GCM으로 암호화해 앱 재실행 후 복원 시도. 비밀번호나 관리자키는 저장하지 않는다. 자동 위치 공유는 하지 않는다.
- 사용자 전용 MOTO HUB Supabase 프로젝트 URL과 `sb_publishable_` **공개키**를 디폴트로 연결해 서버 수동 입력을 없앴다. 필요하면 설정에서 안전하게 변경 가능하다.
- 주행 기록의 GPX 가져오기: ACTION_OPEN_DOCUMENT + 크기 상한 8MB, 5만 좌표 상한, 시간·순서·위도경도 확인, DOCTYPE/외부 엔티티 차단, 실패 시 임시 파일 삭제.
- 기록 선택 후 GPX 내보내기 / 지도 열기 / **명시적 확인을 거친 누적 주행거리 반영**(기존 반영 기록 중복 반영 차단) / 기록 삭제.
- 통합 ZIP 백업 내보내기: JSON, 사용자 등록 차고 사진, 원본 트랙, 가능한 경우 GPX, 설명서. 개인정보 경고 표시. 로그인 토큰 포함하지 않음.

### 기능 및 안전
- GPS 실시간 거리·속도·경과시간 표시, 비현실적 GPS 점프(250 km/h 초과)는 거리 누적 계산에서 제외한다.
- 분석/계기판 반영값은 기기 GPS 계산치로 **실제 오도미터와 다를 수 있다**. 확인 없이 자동 적용되지 않는다.
- GPS 가져오기는 입력 GPX 내 **기록 시각이 있는 트랙/루트 좌표만** 수용한다. 시간 없는 탐색용 코스 파일은 주행 기록으로 위조해서 넣지 않는다.
- 이전 정비·매물·친구·그룹·연식별 카탈로그/사진 검색·JSON 백업 기능 유지.
- 프로젝트 버전 `4.0.0-alpha6-k` / versionCode 416.

## 실제 수행한 검증
- 기존 자바 순수 JVM 테스트: 정비/기변 19, 서버 설정 16, 빠른 입력 12, 모델 사진 분기 12 → **59개 통과**.
- GPX import + 거리 계산 + 악성 XML/시간 역순/누락 거부 → **16개 검사 통과**.
- 통합 ZIP 백업 구조: JSON/원본 GPS/GPX/이미지/안내문 검사 **통과**.
- 카탈로그 49개 브랜드·522개 모델, ID 중복 방지 검사 **통과**.
- Java 17 파서로 Java 소스 30개 파일 구문 검사 **통과**.
- Android SDK/빌드 도구 미설치 + 외부 다운로드 DNS 차단으로 **전체 Android APK 컴파일·실기기 설치 테스트 미수행**. 파일은 실제 설치 가능한 APK가 아니라 소스 ZIP이다.
- 세션 암호화 복원, GPX 가져오기 Android SAF, OSM 화면, 실시간 GPS/Fgs, 백엔드 두 단말 연동은 **기기 동작 검증 전**.

## 정확히 남아 있는 항목
- 세상의 모든 브랜드·모델·트림·연식별 사진을 보장하는 데이터베이스는 아니다. 49개 브랜드/522개 모델, NHTSA(미국 자료) 확장 및 Commons 사진 검색 후보 기반이다.
- 통합 ZIP **원터치 복원은 미구현**. ZIP 안의 `MOTO-HUB-data.json`을 앱 JSON 복원으로, `gpx/`는 GPX 가져오기로 개별 복원할 수 있다. 사진 자동 복원은 미지원이므로 재설치 전 원본을 보관해야 한다.
- 업데이트 매니페스트 서버 주소는 여전히 미배포이며, APK 빌드 후 업데이트 배포 인프라를 별도 구축해야 한다.
- 매물 실시간 자동 수집·알림, 경로 안내 내비게이션, 푸시 알림 등 **외부 제공자/서버가 필요한 기능**은 구현 완료로 보고하지 않는다.
- GitHub Actions 실행 환경에서 `./gradlew :app:assembleDebug`를 실행하면 디버그 APK를 만들 수 있도록 워크플로우 갱신. GitHub 호스팅 러너에서 생성한 기본 디버그 서명은 재빌드마다 달라질 수 있으므로 기존 앱 업그레이드/데이터 이전 전 백업이 필요하다. 릴리스 배포에는 본인이 관리하는 일관된 앱 서명키가 필요하다.
