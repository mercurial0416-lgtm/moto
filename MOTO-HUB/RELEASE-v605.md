# MOTO HUB v605 · 자동연결 진실성, 분할 경로, 실차 검증

1. **서비스 시작 요청 ≠ 성공:** 카르도 연결 직후 Android 위치 서비스 요청을 보내면 v605는 `요청됨`을 표시하고, 실제 RideService가 자동감시 상태에 들어간 뒤에만 `준비 완료`로 승인합니다. 요청은 바이크/고유 토큰별로 결합되고 25초 무응답은 실패입니다.
2. **제한된 재시도:** Android가 자동시작을 차단할 경우 반복 루프를 만들지 않고 90초 자동 재시도 제한, 명시적인 재시도 버튼과 알림을 제공합니다. OBD 상시 감시의 기존 유한 backoff는 보존합니다.
3. **카르도 이벤트 중복:** Headset/A2DP 프로필 응답을 프로필별 한 번만 집계하고, ACL 연결 해제 이벤트는 오디오 프로필을 추가 확인한 뒤 판단합니다. 동반 기기 감지와 ACL의 짧은 중복을 필터링합니다.
4. **분할 GPS 전체 검증:** 자동 기록 종료 시 원본을 변경하지 않고 하나의 UUID 세션 내 모든 구간의 .done 마커, 전체 좌표 읽기, 파일 갯수와 쓰기 개수를 검증한 뒤 첫 주행 완료를 인정합니다. 누락 시 명확한 오류를 보이고 이전 정상 기록은 유지합니다.
5. **실시간 UI 동기화:** 연결 도우미의 상단 상태와 '지금 할 일' 버튼을 8초 주기로 확인된 실제 상태에 맞춰 갱신합니다. 화면을 다시 열어 중첩 팝업을 생성하지 않습니다.
6. **첫 주행 검증 단계:** 연결 요청, 자동 감시, ECU 속도, GPS 시작, 구간별 완료 및 충분한 실제 이동을 구분합니다.
7. **진단 익명화:** 보고서에서 사용자가 지정한 OBD/카르도 장치 이름을 전부 제외합니다. MAC/좌표/원본 ECU 응답을 노출하지 않습니다.
8. **실차 검증 안내:** 듀크390/Freecom 2X를 위한 정차 상태 읽기 전용 검사, 카르도 오디오 연결, 화면 OFF/절전/블루투스 재연결 확인 항목과 첫 GPS 경로 검증을 보여줍니다. 실제 실차 결과가 없으면 통과 처리하지 않습니다.

테스트 패키지 `com.motohub.next.obdpreview605`. 기존 설치 앱과 저장 기록은 자동 이전되지 않으며 사용 중인 v599/v604는 삭제하지 마세요. Android 백그라운드 정책 및 실차 ECU PID 응답은 시뮬레이션만으로 보장할 수 없습니다.
