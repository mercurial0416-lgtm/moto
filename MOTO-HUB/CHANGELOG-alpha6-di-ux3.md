# MOTO HUB Alpha6-DI(518) UX3 — PREBUILD ONLY

본 체크포인트는 UX2 소스를 기반으로 개선한 **빌드 전** 소스입니다.
Android 컴파일, 설치 APK 생성, 실제 스마트폰·차량 작동 검증은 수행하지 않았습니다.

## 실제 변경
- 여러 정비항목 입력 중 자동 임시저장과 동일 바이크 재개. 묶음 DB 저장 성공 후에만 초안 삭제.
- 영수증/작업 사진 기록당 최대 5장: 보기, 슬롯별 교체 및 삭제, 기록/바이크 삭제 시 관련 첨부물 정리.
- 기존 영수증 한 장 파일명 완전 호환; ZIP 백업/검증/복원에서 추가 슬롯 지원.
- OCR: 구글 ML Kit 한국어 모델을 앱에 번들하는 설계. 사진에서 날짜/금액/주유량/단가 제안, 사용자가 직접 확인해야 입력칸에 적용. OCR만으로 자동저장 절대 하지 않음.
- 가득→가득 주유 데이터를 이용한 수동 계기판 기반 실연비 및 거리당 주유비 표시.
- 바이크별 정비 주기 직접 입력·적용: 공식 주기라고 주장하지 않으며 사용자 확인 후 저장; 설정은 메인 JSON 내 serviceIntervals에 보관해 ZIP 백업에 포함.
- UI: 작성 중 묶음 임시저장 접근 버튼, 첨부사진 장수 표기, 확장 입력 필드 자동 펼침.
- ECU/OBD2 읽기·GPS 녹화·친구 위치 공유·개인키 체계는 건드리지 않음.

## 검증 범위
- 순수 Java 새 편의성 테스트 37 assertions PASS
- 5장 영수증 실 ZIP 백업/무결성 읽기/복원 14 assertions PASS
- 변경 코드 UI/보안 소스 연결 정책 21 checks PASS
- 기존 백업, 복원, 암호화, 대용량 기록, UI, 오프라인 지도 등 선택한 회귀 스크립트 8개 PASS
- Java 구문 138개 PASS (type resolution / Android SDK compilation 아님)

## 남은 과제 / 제한
1. Android SDK 컴파일·Lint / 실제 기기에서 UI/OCR·화면회전 검증 (사용자 지시에 따라 빌드 수행하지 않음).
2. 고정 서명 키를 유지하며 versionCode 518의 APK를 만들어 517 고정키 앱에 덮어쓰기 테스트.
3. 실기기 OCR 정확도/영수증 방향정보 및 사진 파일 장기간 보존 테스트.
4. OBD2 실차에서 표준 ODO 지원 여부 확인(미지원 시 자동입력 금지).
5. 구버전 앱에서 다중 영수증 ZIP 복원 불가 가능성. 최신 버전으로만 복원 권장.
