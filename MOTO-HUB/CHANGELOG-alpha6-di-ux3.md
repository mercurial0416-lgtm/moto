# Alpha6-DI(518) UX3 · 소스 전용 개선

**APK 생성·Android 컴파일·서명 없음. 기존 versionCode 518 유지.**

- 사진에서 날짜·금액·주유량을 온디바이스 한국어 ML Kit로 추출하는 *확인 후 입력* UI 추가. 자동 저장·서버 전송 없음.
- 하나의 정비/주유 기록에 JPG 최대 네 장, 기존 단일 영수증 파일명 호환. 사진 추가·보기·교체·단일 삭제 제공.
- 단일 파일과 2~4번 첨부를 전체 ZIP 및 암호화 ZIP에서 원본 바이트로 복원하도록 통합.
- 묶음 정비 초안을 차량별로 로컬 저장, 앱을 다시 열면 명시적 선택 후 복구. 저장 완료 시 초안 삭제.
- 차량별 사용자 입력 정비 간격. 매뉴얼에 맞춰 사용자가 직접 등록하며 자동 적용 불가. 앱 DB에 저장돼 ZIP 백업 대상에 포함.
- 최근 주유 결제 단가·가득 주유 구간을 이용한 추정 연비를 차량별로 표시.
- 새 주유/정비 저장 직후 영수증 사진 첨부 선택 옵션.
- 기존 OBD2 읽기 전용 정책, 개발자 모드의 수동 확인 ODO 기능 유지. 제조사 공식 주기를 임의로 기입하지 않음.
