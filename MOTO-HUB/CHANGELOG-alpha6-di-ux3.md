# MOTO HUB Alpha6 DI(518) UX3 — APK 빌드 전 소스

- 묶음 정비 작성 내용의 바이크별 자동 임시저장·30일 내 수동 복구·저장 완료 후 삭제
- 동일 바이크의 최근 정비 묶음에서 작업 항목과 비용만 다시 불러오기. 날짜·계기판은 복사하지 않음
- 주유·정비 기록 하나에 영수증·작업 사진 최대 4장 첨부, 보기·교체·개별 삭제
- 기존 `record-receipt-UUID.jpg`(사진 1장) 유지, 사진 2~4는 `-2.jpg`~`-4.jpg`
- 전체 ZIP / 암호화 백업·검증·복원에서 여러 영수증 원본 유지
- 사진 자동 읽기: 번들 한국어 ML Kit 온디바이스 OCR을 연결하고 금액·주유량·날짜 후보 표시
- OCR 결과는 확인을 눌러야 입력칸에 반영되며 기록은 **저장 버튼을 누르기 전에는 변경되지 않음**
- 최근 주유값 기준 평균 리터당 비용, 가득 주유 사이 거리/주유량에 근거한 **추정 연비** 표시
- UI 및 데이터 입력 오류를 막는 소스 테스트 강화. **APK 빌드·Android 컴파일은 하지 않음**

## 주의

- 최신 APK로 사용할 수 있는 버전은 여전히 기존 고정 서명 517입니다. UX3는 소스 전용 518입니다.
- Android 빌드 전 신규 ML Kit 의존성, 권한·서명·실기기 OCR/카메라 동작 검증이 필요합니다.
- 기존 서명키는 ZIP에 포함하지 않았습니다.
- ECU/OBD2에서 범용 계기판 누적거리 PID를 가정하지 않았고 강제로 자동 입력하지 않습니다.
