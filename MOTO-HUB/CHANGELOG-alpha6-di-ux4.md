# MOTO HUB Alpha6 DI(518) UX4 — APK 미생성 소스 개선

- 영수증 카메라 직접 촬영 지원: 카메라 앱에서 `EXTRA_OUTPUT`으로 개인 캐시에 사진을 만들고 촬영 취소·실패·OCR 완료 뒤 정리
- FileProvider 접근 범위를 개인 캐시의 `receipt-camera/`로만 제한. 사진을 일반 사진첩 또는 서버에 자동 저장하지 않음
- 기울어진 JPEG의 EXIF 회전 정보를 OCR에 반영하고, 저장된 JPEG 영수증은 방향을 바로잡은 픽셀로 재인코딩
- OCR 결제금액 여러 후보 제시: 총결제·실결제·카드결제 우선; 세부금액 및 세금 혼동을 줄이고 선택은 사용자가 수행
- 정비 묶음 등록 화면에 선택 수/예상 총액 실시간 표시, 엔진오일+필터 빠른 선택, 선택 해제, 최종 항목별 결제금액 확인
- 새 정비/주유 기록 작성 시 '저장 후 영수증 첨부' 선택 항목 추가. 선택하지 않으면 저장 흐름 그대로 유지
- 촬영 파일 24시간 이상 경과 시 안전한 이름/경로에 한해 정리; 기존 라이딩/백업/정비 사진은 대상에서 제외
- 기존 1~4장 영수증 ZIP 및 암호화 ZIP 포맷 유지

**주의:** 새로운 APK는 생성하지 않음. Android Java 컴파일만 GitHub CI에서 통과 (GitHub Actions 39411964902), APK는 생성하지 않음. 카메라 앱별 호환성 및 OCR 인식률은 실기기 검증 필요.
