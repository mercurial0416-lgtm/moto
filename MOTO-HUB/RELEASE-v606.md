# MOTO HUB v606 · 듀크390 설정 통합 및 자동주행 기록 누락 대응

- **차고 → 현재 바이크 이름 클릭 → 내 바이크 설정 → OBD·카르도·자동 라이딩 설정.** 차량 선택은 별도 '변경 ▾' 버튼으로 분리했습니다. 홈 화면의 내 바이크 이름도 설정 화면으로 열립니다.
- 자동 기록이 안 되었을 때 **내 바이크 설정 → 오늘 주행 기록이 안 됐을 때 · 원인 확인**에서 해당 바이크의 자동 기록 방식, OBD/카르도 등록, GPS 동의, Android 권한, 시작 요청/응답, 단계별 실패 시각을 확인합니다. 그날의 실제 데이터가 없으면 추정임을 명확히 표시합니다.
- OBD/카르도 자동 출발 감시가 **대기 중**이어도 **라이딩 탭 → 지금 GPS 기록 시작 · 자동감지 기다리지 않기**를 눌러 사용자가 직접 GPS를 기록할 수 있습니다. 자동감시를 임의 해제하거나 이전 파일을 덮어쓰지 않습니다. 좌표가 실제 수신된 후만 기록이 유효합니다.
- 자동 감시 중지 버튼은 별도 보조 버튼으로 유지했습니다. 원본 GPS를 자동 삭제하지 않습니다.
- **독립 APK 경고:** `com.motohub.next.obdpreview606`은 기존 v599/v605 등과 데이터·기기 등록 설정을 공유하지 않습니다. 새 테스트 APK에 바이크/OBD/카르도가 등록되지 않았다면 자동 라이딩은 동작하지 않습니다.
- 기존 v605의 백그라운드 위치 권한, Cardo FGS 준비 ACK, ECU 속도 PID 지원 및 분할 GPS 세션 검증 기능은 유지했습니다.

실차에서 휴대폰·2024 Duke 390·Bluetooth 동글·Freecom 2X를 직접 연결한 결과는 별도로 확인해야 하며, 소스·UI 테스트로 실차 검증을 대체할 수 없습니다.
