# MOTO HUB v603 · 연결 설정 개선 (테스트 빌드)
- 먼저 **카르도 + OBD**, **OBD만**, **카르도 + GPS** 중 하나를 선택합니다. 선택 자체가 자동기록을 켜지는 않습니다.
- ECU에서 센서 값이 실제로 수신된 후에만 **이 동글로 사용하기**가 표시됩니다. 페어링만 된 상태는 수신 성공으로 표시하지 않습니다.
- 동글을 교체하면 카르도·GPS 안전망 등 기존 동의가 해제될 수 있음을 **등록 전에** 보여주고 재설정 경로를 제공합니다.
- 위치/알림 등의 권한은 필요한 장치 등록을 마친 뒤 요청합니다. 장치 자체를 선택할 때 필요한 Bluetooth 권한은 그 단계에서 요청합니다.
- 화면이 열려 있는 동안 현재 ECU 속도, GPS 좌표 수신, 정확한 MAC의 Cardo 오디오 연결을 8초 주기로 확인합니다. 화면이 닫히면 이 조회는 멈춥니다.
- 실패 원인을 확정하지 못했을 때는 추정임을 명시하고 Bluetooth/권한/ECU 검사로 바로 이동하게 합니다.
- **첫 주행 설정 검증 완료**는 자동기록의 실제 GPS 파일이 `.done`으로 검증되고 두 개 이상의 좌표와 0.1 km 이상의 관측 거리가 있는 경우에만 표시합니다. 계기판 ODO를 덮어쓰지 않습니다.
- 현재 빌드는 **`com.motohub.next.obdpreview603`** 테스트판입니다. 기존 앱 옆에 설치되며 기존 데이터를 이전하지 않습니다. 실제 Duke 390 및 Freecom 2X 실차 동작은 별도 검증이 필요합니다.
