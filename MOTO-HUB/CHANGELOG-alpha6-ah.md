# MOTO HUB 4.0 Alpha6-AH

- 홈 화면의 정비 예정일이 30일 이내 또는 잔여 주행거리 500km 이내인데도 `정비 정상`으로 표시되던 UI 문제 수정.
- `곧 점검` 상태와 황색 배지 및 `SERVICE SOON` 보조 문구 추가. 홈의 `다음 정비까지` 카드에도 경고 우선 표시.
- 잘못된 날짜가 포함된 가져온 정비 기록 때문에 홈 정비 상태 표시가 중단되지 않도록 날짜 오류 처리.
- 기존 정비/주유/매물/GPS/GPX/Supabase 친구·그룹/카탈로그/백업·복원 코드 및 위치 공유 동의 절차 유지.
- 순수 Java 회귀 테스트 및 홈 UI 연결 검사 실행. Android APK 빌드와 실제 단말 검증은 별도 확인 필요.
