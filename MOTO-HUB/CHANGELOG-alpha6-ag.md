# MOTO HUB 4.0 Alpha6-AG (versionCode 438)

## UI: 바이크 사진 자동 표시 실패 시 다른 후보 재시도
- 이전 버전: Wikimedia Commons 검색에서 첫 번째로 선택된 이미지 다운로드가 실패하면 다른 후보를 시도하지 않아 사진이 표시되지 않음.
- 개선: 브랜드/모델명이 일치하고 JPEG/PNG/WebP 및 출처/라이선스 조건을 통과한 후보를 최대 3개 순차 시도.
- 정확한 연식 후보 다운로드가 모두 실패하면 동일 모델 참고 사진 검색으로 재시도. 연식 확인 여부는 기존처럼 별도 표기.
- 사진 파일 캐시 저장에 실패해도 이미 다운로드한 이미지는 화면에 표시.
- 사용자 직접 등록 사진 우선, 출처 표시, GPS·친구/그룹·동의/접근제어 등 기존 로직 유지.

## 검증
- PhotoRetry 순수 Java 오프라인 테스트 8건, 사진 경합 10건, 사진 파일명 18건, 정비/비용 20건, 빠른 입력 12건, 카탈로그 및 UI 연결 검사 통과.
- GitHub Actions SDK 설치 경로/실행 권한 및 체크포인트 명칭을 AG로 갱신.
- 실제 Commons API 및 이미지 다운로드, Android APK 빌드, 실기기 실행은 이 체크포인트에서 미검증.
