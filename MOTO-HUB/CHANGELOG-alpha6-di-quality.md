# DI(518) prebuild quality revision — APK 빌드 금지

- 업데이트 서버 접속 전에 설치 APK가 고정 인증서와 일치하는지 확인. 임시 디버그 서명 설치본은 자동 다운로드를 차단하고 백업 후 전환 안내.
- 업데이트 APK 다운로드 시 저장소 가용 공간(파일 2배 + 32MiB)을 사전 계산하고 부족하면 네트워크 전송 전 차단.
- 설정 → 개인정보 및 라이딩 → `라이딩·OBD2 사전 점검` 추가. 위치/GPS/알림/배터리 최적화/Bluetooth을 읽기 전용 점검하고 Android 설정으로 이동. 권한 자동 승격, 자동 그룹 공유 없음.
- 공유 시작 서버 실패 시 `공유 시작 요청 중` 상태가 무기한 남는 문제 수정. 서버 응답과 권한 재검증 후에만 실제 위치 공유 상태 활성화.
- 기존 기능과 보안을 유지하며 Android APK 컴파일, assemble, 서명 작업은 **일절 실행하지 않음**. 순수 Java/소스 검사만.
- 외부 검증: Supabase MOTO HUB 프로젝트 ACTIVE_HEALTHY, public 테이블 7개 RLS 활성화, RPC security_invoker. 0행의 비활성 사용 데이터; 실제 계정·GPS·실차 테스트 미실시. 관리자 RLS INFO 1건은 비공개 스키마 의도적 정책 부재로 보임. 조회만 하고 DB 변경하지 않음.
- 가장 큰 남은 외부 의존성: GitHub Secrets 고정 개인키 등록, 실기기 GPS/OBD 및 그룹 위치 공유 통합 실험.
- 사진 캐시를 64MiB 이상일 때 보수적으로 정리: 7일 지난, Wikimedia 자동 다운로드가 확실한 모델 사진만 제거. 갤러리에서 직접 선택한 사진/불명확한 메타데이터/심볼릭 링크 보호.
- 실제 서버에서 읽기 전용 검사: MOTO HUB Supabase 프로젝트 정상, public 테이블 7개 RLS 활성화, 그룹/위치 SELECT 정책에 구성원 조건, 위치 만료 조건 확인. 실제 GPS 전송 테스트 미실시, 데이터 수정 없음.
- 친구·그룹 설정의 서버/세션/공유 상태를 기기 안에서 조회하는 진단 화면 추가. 서버 개인키/좌표 표시 없음.
- GPS 사전점검에서 현재 주행 중 마지막 위치 수신 시간과 좌표 건수를 표시.
- 원본 518 PREBUILD 버전코드를 유지(동일 518의 코드 리뷰 개정판이며 APK는 한번도 빌드하지 않음).
