# MOTO HUB Alpha6-DI (518) — 소스 수정 완료, APK 빌드 전 단계

- 완전 중단된 암호화 ZIP 복호화 임시파일을 다음 앱 프로세스 시작 때 자동 삭제. GPS 롤백 백업 폴더는 삭제하지 않음
- 오래된 복원 준비 폴더만 보수적으로 정리하고 심볼릭 링크 등 예상치 못한 항목은 삭제하지 않음
- 업데이트 매니페스트 기본 주소와 고정 서명 인증서 SHA256 검증 추가. 임시 디버그 서명 설치본 업데이트는 중단하고 데이터 백업 안내
- 실제 GitHub main/updates/manifest.json에 검증된 고정 서명 DH(517) 정보 게시. 다음 버전의 고정 서명 APK가 배포되기 전까지 앱 업데이트에는 새 버전이 표시되지 않음
- 매물 및 정비·주유 화면은 30개 단위 앞/뒤 페이지로 렌더링. 1만 건도 끝까지 접근할 수 있으며 원본 기록은 수정하지 않음
- 앱 업데이트 다운로드는 최대 4번, 제한된 HTTPS 리다이렉션만 허용하고 진행률을 25% 간격으로 안내
- 새 고정 서명 릴리스가 빌드된 **뒤에만** 매니페스트를 생성하고 사용자 확인에 따라 GitHub Release를 게시할 수 있도록 CI 코드 준비(미실행)
- 로컬 사진(직접 촬영/캐시)을 1200픽셀 기준으로 샘플링해 고해상도 원본의 메모리 폭증 방지
- 저장 매물 검색은 180ms 디바운스로 렌더링 회수를 줄임
- 기존 OBD2 읽기 전용/명시적 동의/최대 8회 재연결, 최근 정비·주유 입력 기능 유지
- 모든 변경은 **소스 단계**. 사용자 요청에 따라 Android assembleDebug / assembleRelease / APK 서명 작업은 실행하지 않음

## 후속 검증 필요
- 휴대폰 직접 설치와 업데이트는 새로운 518 고정 서명 APK 빌드 후 실제 단말로 검증해야 함
- GitHub Secrets 서명키 설정이 미완료라 자동서명은 아직 사용할 수 없음
- GPS 절전, OBD2 실제 차량 센서, Supabase 서버 권한은 현장 실측/계정 연결이 필요
