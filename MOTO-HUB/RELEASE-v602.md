# MOTO HUB v602 – 쉬운 연결 설정
기존의 긴 OBD/카르도 설정 화면을 처음 보는 사용자가 순서대로 따를 수 있게 분리합니다.

## 앱에서 따라 하는 순서
1. **바이크 확인:** 바이크 설정에서 연결 도우미 열기. 현재 바이크가 표시됩니다.
2. **OBD:** 바이크 키 ON, 휴대폰 Bluetooth 페어링, 앱에서 동글 등록. 등록만으로 ECU 연결 성공은 아닙니다. 정차 상태에서 **OBD 실제 연결 검사**로 속도/RPM을 조회합니다.
3. **카르도:** Freecom 2X와 휴대폰을 페어링하고 앱에 카르도로 등록. 연결 감지로 OBD 감시가 시작될 수 있습니다. OBD만 쓰면 생략할 수 있습니다.
4. **자동기록:** 카르도 연결 시 자동 감지 또는 OBD 상시 대기 중 선택. OBD가 없거나 ECU가 속도를 응답하지 않는 경우에만, 별도 동의를 받아 GPS 안전망을 활성화할 수 있습니다.

화면의 **현재 상태**는 기기 등록과 실제 ECU 속도 수신을 구별합니다. GPS 기록도 신선한 좌표가 있는지 구별합니다. 위치·주변 기기·알림 권한 부족은 최우선으로 안내하고, Android 백그라운드 제한 시 알림을 눌러 시작해야 할 수 있음을 안내합니다. 불필요한 ODO/센서/원시 로그/연결 해제 버튼은 고급 설정에 보존했습니다.

이 버전은 `com.motohub.next.obdpreview602` 패키지로 **기존 설치 앱 옆에 설치하는 디버그 테스트판**입니다. 공식 앱 데이터는 자동으로 옮겨지지 않습니다. 실제 듀크390 ECU ODO 지원 여부, 자동시작 신뢰성, 전력 소모는 실차 확인이 필요합니다.
